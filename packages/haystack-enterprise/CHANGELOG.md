# Changelog

## 0.1.0

Initial release.

- **File** resource: Upload, Get, Get Many, Get Meta, Update Meta, Update Meta Bulk, Delete, Delete Many
- **Index** resource: Get, Get Many
- **Search Session** resource: Create, Get Many, Delete
- **Service** resource: Get, Get Many, Search (Streaming), Chat (Streaming)
- **Authentication**: choose API Key or OAuth2 on the node. The OAuth2 credential supports Dynamic Client Registration (RFC 7591) against an identity provider like Authentik 2026.8+ — no manual client ID/secret needed.
